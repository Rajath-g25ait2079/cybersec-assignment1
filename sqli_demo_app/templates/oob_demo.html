📡 Out-of-Band SQL Injection Demo

In real-world OOB SQLi, the database sends data to an attacker-controlled server via DNS or HTTP requests (e.g., using UTL_HTTP in Oracle or xp_cmdshell in MSSQL).

This demo simulates OOB exfiltration using a custom SQLite function exfiltrate() that logs extracted data to a file — representing the attacker's DNS/HTTP listener.
